# 🎮 Python Minecraft Clone

这是一个使用 Python 和 Ursina 引擎制作的简易版我的世界。

## ✨ 特性
- **20种基础方块**：包括草、泥土、石头、各种矿石等。
- **无限地形**：使用柏林噪声 (Perlin Noise) 生成自然起伏的山脉和河流。
- **第一人称控制**：支持移动、跳跃、破坏和放置方块。
- **窄视野模式**：FOV 设置为 50，提供更具沉浸感的视觉体验。

## 🛠️ 如何运行

### 1. 安装依赖
你需要 Python 3.11 或更高版本。
```bash
pip install ursina perlin-noise pillow
